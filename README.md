# Aura Spa

Aura Spa application with a Next.js frontend and a NestJS backend.

- `aura-spa-frontend/`: customer, staff, manager, and owner web application.
- `aura-spa-be/`: API, database migrations, seed data, and Docker configuration.
- `docs/`: project documentation.

## Local development

Use Node.js 22. Install dependencies with `npm ci` in each application directory.

For backend configuration and startup, see `aura-spa-be/docs/README.md` and `aura-spa-be/.env.example`.

For frontend startup, see `aura-spa-frontend/README.md`.

Local environment files, dependencies, and generated build files are excluded from Git.
